Automatically switch WordPress themes for mobile visitors.

== Description ==

TearSnow Mobile Theme Switcher is a plugin for setting independent mobile themes for WordPress, developed and maintained by [TearSnow](https://tearsnow.com).

The plugin detects mobile devices and automatically loads the selected theme while keeping the default theme for desktop visitors.

Features:

* Select any installed WordPress theme as the mobile theme.
* Automatically switch themes for mobile visitors.
* Simple integration with WordPress settings.
* No additional configuration required.

== Installation ==

1. Upload the `tearsnow-mobile-theme-switcher` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the "Plugins" menu in WordPress.
3. Go to "Settings → General" and select your mobile theme.

== Frequently Asked Questions ==

= How does the plugin detect mobile visitors? =

The plugin uses WordPress built-in mobile detection to identify mobile devices.

= Can I use any installed theme as the mobile theme? =

Yes. Any installed and available WordPress theme can be selected.

= Does it affect desktop visitors? =

No. Desktop visitors continue to use the default WordPress theme.
